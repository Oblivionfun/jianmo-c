新增的 `scripts/validate_workbook_semantics.py` 会对四个全年结果的“充放电量”表做日期前向填充后核对：334 天、每天 6 个四小时区间、0:00/24:00 标记、SOC 范围及首末状态。当前回测的四个分支均为 334/334 个日末 SOC=1200 kWh，首日 0:00 为 6000 kWh；这证明导出接口和边界记录一致，但不证明逐日短视策略具有全年最优性。
