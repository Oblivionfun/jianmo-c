# 图表替换源

本目录保存用户提供的“图表更改.zip”原始图形、映射清单及候选图。原始图形只作为审查记录，不直接作为论文引用文件。

## 已纳入主稿的图形

- `2.jpg` → `raw_q1_inputs.png`：问题一输入序列（负荷、光伏预测与价格）。
- `4.jpg` → `process_q1_soc.png`：问题一充放电计划与储能状态。
- `5.jpg` → `result_q1_dispatch.png`：问题一购电计划与价格。
- `9.jpg` → `raw_q2_q3_q4_emergency.png`：问题二、三、四的紧急购电量对比。
- `11.jpg` → `result_q4_cost_box.png`：问题二、三、四-2的逐日费用分布。
- `12.jpg` → `result_q4_3_series.png`：问题四-3逐日费用序列。
- `13.jpg` → `process_q2_q4_compare.png`：问题二与问题四-2的逐日费用对比。
- `14.jpg` → `sensitivity_pv.png`：光伏保守系数敏感性分析；数值与 `results/sensitivity_forecast.csv` 核对一致。

问题三调整量—紧急购电量散点图没有直接采用压缩包版本，而是用当前 `results/daily_metrics.csv` 重绘，当前相关系数为 `r=0.0201`（四舍五入）。
