# C题版本更新说明

本轮更新的目标是让模型在经验贴的“统一状态价值函数”叙事下仍能经受题面、信息集、账单和分支状态的反向检查。

## 模型更新

- 新增 `state_value.py`：实现 Q3 B 结算分项、因果日电量—日内形状负荷预测和有限网格库存价值 DP。
- `solve_c.py` 的 Q2–Q4 负荷预测改为目标日前同类型日优先的日电量—日内形状中位数；光伏改为目标日前三日中位数并乘 0.9 保守系数。
- Q3/Q4-3 账单改为计划基准费、调减费、调增费和紧急费四项相加，逐日记录各项。
- Q4-2 与 Q4-3 使用相同日初 SOC 的独立分支，避免把一个问题的日末状态带进另一个问题。
- 每次 LP/MILP 求解后运行 SOC、功率、非负性和初始状态审计；充放电重叠量被记录，不能静默忽略。

## 验证更新

- `results/forecast_diagnostics.csv`：334 天、四类预测的 MAE、MAPE 和偏差。
- `results/value_dp_q1.json`：Q1 LP 与 5 kWh 网格 DP 的独立对照。
- `tests/test_state_value.py`：结算等式、目标日前信息边界和 DP 互斥动作测试。
- `validate_results.py`：新增预测选择、DP 有限性、Q3/Q4-3 账单分项等式检查。

## 结果解读边界

日电量—形状分解使负荷预测误差下降，但在本次保守光伏设定下紧急购电仍是主要费用来源；因此不能只用 MAPE 下降推断所有调度指标都会下降。Q3 总费用现在严格反映计划基准费用，不能与旧版少算账单的结果直接比较。Q1 网格 DP 是独立近似核验，不替代 MILP 的提交结果。Q2–Q4 全部为本地附件回测，不能写成官方排名、奖项或正式测试成绩。
