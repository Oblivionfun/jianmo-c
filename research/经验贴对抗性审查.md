# 经验贴与附件论文的对抗性审查

## 材料边界

本审查把用户提供的小红书截图和《微网电力调控_四问完整稿.pdf》视为外部经验材料。它们不是 CUMCM 题面、官方模板或组委会规则，不能替代 `input/题面/C题.txt` 与附件数据。经验材料中的数字、结论和“B 口径”只有在当前题面、当前附件和当前代码重新复现后才能进入论文。

PDF 文件共 31 页，文件 SHA-256 为 `2e89988c587eaaac8a571fc5b75584096d4136f3ecd96c2b2e00780402cad268`。其摘要和正文反复出现“小红书：诸位加油”水印，元数据作者为“我是小席同学”，主题字段为“B口径取消结算”。这说明它更适合作为思路参考，不能直接作为匿名竞赛论文或可核验结果来源。

## 必须抵抗的部分

1. **不能把经验材料的结果当成本题结果。** PDF 报告的 35,126.948589 元、13,566,395.37 元、13,024,699.25 元等数字没有由本工作区当前代码和附件重现；本版本不引用它们。
2. **B 结算必须按题面文字落账。** 当前实现采用“计划基准费 + 计划高于调整部分的 0.5 倍费用 + 调整高于计划部分的 1.5 倍费用 + 紧急购电费”。旧版把 `q_adjusted` 直接乘正常价格，再加调整费，少算了调减时的计划基准费；已修正并用逐日等式审计。
3. **情景路径不能冒充因果执行。** 经验材料承认其部分路径递推知道未来情景，这只能作为规划近似，不能作为真实在线策略的证明。本版本全年主结果仍是按日期顺序、只用历史信息的回测。
4. **“LP 松弛必然互斥”有条件。** 该结论依赖非负价格、允许弃用富余供能且不含额外耦合成本；它不能自动覆盖所有带惩罚、退费或退化成本的扩展。本版本 Q1 保留显式互斥 MILP，其他场景执行后检查充放电重叠量，不把条件性命题写成一般定理。
5. **Q4-2 和 Q4-3 是两个分支。** 旧版让 Q4-3 从 Q4-2 的日末 SOC 开始，造成分支串联；本版本二者从同一日初 SOC 独立运行。
6. **水印、作者元数据和未经核验引用不能进入提交稿。** 经验 PDF 的版式可供学习，不能直接复制；当前论文草稿不包含其水印、署名或未复现数字。
