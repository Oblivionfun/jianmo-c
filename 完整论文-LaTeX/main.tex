\begin{abstract}
题目同时涉及固定与波动电价、逐步公开的负荷和光伏信息，以及储能调度。研究以十分钟为时间步长，建立统一的能量平衡模型，分别记录常规购电、紧急购电、充电、放电和弃光，并用储能递推、功率边界、容量边界和跨日状态约束检查物理可行性。问题一用带充放电互斥的混合整数线性规划求解，并用5\,kWh有限状态网格动态规划交叉核验；问题二将负荷预测拆成日电量水平和日内形状，光伏则取目标日前三日中位数并乘0.9作为计划输入；问题三在0、6、12、18时锁定已执行前缀，得到带非对称结算的滚动基线；问题四在附件4的波动价格下分别重算问题二和问题三。文中还给出分裂保形、历史误差场景和CVaR的扩展接口，并用边际收益条件说明何时值得更新计划。给定当前附件和代码，问题一单日购电量为59482.699\,kWh，经济费用为35126.949\,元；求解器的破平局正则项使内部目标值为35126.986\,元。2025年2月1日至12月31日的本地研究基线总费用分别为Q2 16206550.45\,元、Q3 17178137.27\,元、Q4-2 16989713.48\,元和Q4-3 17945143.08\,元。这些数字只代表当前附件、代码和结果文件对应的研究基线；跨日状态、结算口径等边界修复并重跑前，不将其解释为官方成绩。
\end{abstract}

\section{问题重述与数据审计}
\subsection{题目任务}
题目要求以十分钟为时间步长安排常规购电、紧急购电和储能充放电。问题一给出单日价格、负荷和光伏预测，并固定日初、日末储能；问题二扩展到全年实际负荷和光伏，规定每天0:00制定计划，预测偏差由紧急购电补足；问题三在0、6、12、18时发布未来24小时的整点光伏预报，只能调整尚未执行的计划；问题四将固定价格换成附件4的波动价格，分别重算问题二和问题三。论文格式遵循官方规范\cite{cumcm}。
\subsection{数据口径与信息边界}
附件1给出144个十分钟记录，作为问题一的价格、负荷和光伏预测；附件2给出2025年365天的实际负荷和光伏；附件3给出每日四次、每次24个整点值的光伏预报；附件4给出每日144个十分钟价格。全年评估窗口取2025-02-01至2025-12-31，共334天。Q2和Q4-2的历史点预测只读取严格早于目标日的行，Q3和Q4-3再使用目标日0、6、12、18时已经公开的附件3预报。功率先乘\(\Delta t=1/6\) h进入能量平衡，费用由同一时段的价格乘购电量得到；标签“0:00+1”表示次日0:00。Q2与Q3在0:00使用的光伏预测来源不同，因此两者差异不能单独归因于预报更新时间。

\subsection{信息集与预处理流程}
四个子问题共用能量平衡和储能状态方程，但每次决策可见的信息不同。问题一把附件1中的单日负荷、光伏预测和价格视为已知；问题二在每天0:00只用目标日前的历史样本生成计划，实际负荷和实际光伏留到事后结算；问题三在0、6、12、18时接收新光伏预报，只重算尚未执行的区间；问题四只替换价格序列，分别沿用问题二和问题三的信息边界。按这个划分，可以分别观察预测误差、更新时间和价格时序的影响。

读取数据时，程序先将Excel日期序列转换为真实日期，再按结构计数核对记录数和字段数。附件3同一天的四条预报可能只有首行带日期，后续行沿用该日期；“预报1小时”至“预报24小时”先加到发布时刻，再映射到结果模板的十分钟槽。发布前的空档用首个可用预报保持，端点取最近值。结构计数结果为：附件1有144条记录和432个数值字段，附件2和附件4均为365\(\times\)144个功率或价格记录，附件3为365\(\times\)4\(\times\)24个预测值；当前读取未报错。日期唯一性、两张实际表的日期对齐以及附件3发布时刻集合仍需在提交前用显式断言复核。

时间标签还存在“区间起点还是终点”的解释空间。当前实现按模板列序读取，不做循环平移：首列作为内部$t=0$，末列“0:00-0:10+1”只作次日标签，$S_0$作为该窗口的起始状态。题面未给出另一种时间戳解释的裁决，正式提交前需结合模板样例并做前后各一槽的敏感性核对。

全年回测按结果模板取2025-02-01至2025-12-31的334天。功率进入能量平衡前统一乘以\(\Delta t\)，费用由对应时段的价格乘购电量计算。原始附件保持不变；字段、取值范围和输入哈希由\texttt{scripts/validate\_input\_xml.py}记录，结果文件由当前代码写入results目录。

\subsection{数据审计结论}
审计显示，附件的主要风险来自时间索引、功率与电量换算，以及预测信息的可得时点。程序按真实日期和十分钟序号建索引，再执行功率乘\(\Delta t\)；内部槽位遵循附件和模板的列顺序，模板末列“0:00-0:10+1”只用于导出，不参与状态递推。附件3的空白日期只前向填充为同日标签，预报值按“发布时刻+相对小时”映射；除计划侧明确的0.9保守系数和非负截断外，不对预测数值做人工修正。由于附件3只提供发布后的整点值，发布时刻至“预报1小时”之间没有单独观测；当前基线用首个可用值保持填充。这是实现口径，不是题面事实，替代填充方式需另做敏感性分析。

上述检查只能说明输入结构完整、单位转换可追溯，不能据此证明预测准确。预测误差在问题二和问题三的因果回测中衡量；实际负荷和实际光伏只在结算阶段进入误差与费用计算。若把实际值提前送入日内优化，得到的将是无法在线复现的完美信息结果。

后文统一采用“预测用于决策、实际值用于回放”的双轨记录。程序在运行时检查计划和回放的能量平衡，结果文件持久化逐日紧急购电和费用分项；工作簿按模板保存购电计划、充放电聚合量及0:00/24:00储能状态。储能策略、预测改进、预报更新时间与价格替换的影响据此分别核对。

\section{模型假设、符号与统一约束}
\subsection{建模假设}
模型作如下约定：(1)微网可以从外网购电，光伏优先供给负荷或储能，富余部分允许弃用；(2)储能只受题目给出的容量、充放电功率和效率约束，不考虑退化与自放电；(3)每个十分钟区间内功率保持不变；(4)计划阶段保留紧急购电变量作为5倍价格的可行性松弛，在常规购电无上限且价格为正时，理论最优应为0；实际紧急购电只在回放阶段按剩余缺口结算；(5)Q3和Q4-3只重优化尚未执行的区间，已执行前缀保持不变。
第一条约定将光伏视为无边际成本的本地供能，并用弃光量\(u_t\)处理“光伏大于负荷且储能受限”的情形。题目未给出上网电价，余电外送收益不计入目标函数。第二、三条约定统一状态量和控制量的时间口径，使各时段都在同一组功率上限和容量边界下计算。

第四、五条约定回测顺序：先用当时可见的预测生成计划，再用实际负荷和实际光伏计算缺口与账单。预报更新只改变尚未执行的后缀，已发生的功率和储能状态不被事后改写。费用对应一个可以在线执行的策略。
\subsection{变量与能量平衡}
令\(t=0,\ldots,T-1\)表示十分钟时段，\(q_t,e_t,c_t,d_t,u_t\)分别表示常规购电、紧急购电、交流侧充电、交流侧放电和弃光量（kWh）；\(L_t,G_t\)表示负荷和光伏功率（kW），\(p_t\)表示价格（元/kWh），\(S_t\)表示时段起点储能量（kWh），\(\eta=0.9\)。
\begin{equation}\label{eq:balance}
q_t+e_t+d_t+G_t\Delta t=L_t\Delta t+c_t+u_t .
\end{equation}
\begin{equation}\label{eq:soc}
S_{t+1}=S_t+\eta c_t-d_t/\eta .
\end{equation}
\begin{equation}\label{eq:bound}
0\le c_t,d_t\le5000\Delta t,\quad1200\le S_t\le10800,\quad S_0=6000 .
\end{equation}
\begin{table}[H]\centering\caption{主要符号与单位}\label{tab:symbol}\begin{tabular}{lll}\toprule 符号&含义&单位\\\midrule
$q_t,e_t$&常规/紧急购电量&kWh\\ $c_t,d_t$&充电量/放电量&kWh\\ $u_t$&未利用光伏量&kWh\\ $S_t$&储能状态&kWh\\ $L_t,G_t$&负荷/光伏功率&kW\\ $p_t$&外网交易价格&元/kWh\\\bottomrule\end{tabular}\end{table}
能量平衡式左侧列出可供给能量：常规购电、紧急购电、储能放电和光伏；右侧列出负荷、储能充电和弃光。光伏先供给负荷，剩余部分进入储能或\(u_t\)；光伏不足时由储能、常规购电和紧急购电补足。状态方程采用交流侧充放电口径：输入\(c_t\)只有\(\eta\)比例存入电池，输出\(d_t\)需要从电池取出\(d_t/\eta\)。

\(\Delta t=1/6\) h，所以5000 kW的功率上限对应每个十分钟最多833.333 kWh的充电或放电量。\(S_t\)表示时段起点状态，共有\(T+1\)个状态点。问题一另加\(S_T=S_0\)；全年回测把上一日末状态传给下一日初始状态。

问题一加入\(S_T=S_0\)，并用二元变量\(z_t\)施加\(c_t\le5000\Delta t z_t\)、\(d_t\le5000\Delta t(1-z_t)\)，禁止同一时段同时充放电。问题二至问题四沿用这组物理约束，跨日回测再传递日末状态。滚动优化与不确定性建模的写法参考文献\cite{gulotta,honen}。
\subsection{互斥约束与求解接口}
充放电互斥是模型中唯一的离散动作。问题一用二元变量\(z_t\)线性化：\(c_t\le5000\Delta t z_t\)、\(d_t\le5000\Delta t(1-z_t)\)。大M取题目给出的单步功率上限，避免人为放大可行域。问题一采用MILP；问题二至问题四要在334天内反复滚动求解，采用连续LP，并在目标中加入极小的充放电正则项。每次求解后记录充放电重叠量和SOC审计结果。若扩展模型加入退费、负价或其他耦合成本，LP不再自动保证互斥，需要重新启用二元约束。
\subsection{四问共享的输入—输出接口}
四个问题调用同一个调度接口。接口输入负荷、光伏、价格和日初SOC，输出\(q_t,c_t,d_t,u_t,e_t\)及SOC轨迹。差异只来自信息集和账单：问题一输入单日已知预测并固定日末SOC；问题二按日提前计划，实际回放时补紧急电；问题三保留0:00基准计划，只调整后缀；问题四替换价格序列，沿用前两问的信息边界。统一接口让差异可以追溯到预测、更新时间或价格，而不是隐藏在代码分支中。

\section{算法实现与实验设计}
\subsection{信息集驱动的滚动框架}
四个问题使用同一组物理状态和控制量，但不共享未来信息。每天的运行分为三个阶段：信息截面、计划求解和实际回放。信息截面只读取该时刻已经给出的历史观测与预报；计划求解只输出尚未执行的控制量；实际回放在日末读取真实负荷和真实光伏，计算紧急缺口、账单分项以及下一日初始SOC。后来才出现的数据不回写到已执行前缀。

设第$d$天的信息集为$\mathcal I_d$，日初储能为$S_{d,0}$，计划算子记为$\Pi(\mathcal I_d,S_{d,0},p_d)$，则计划轨迹可写为
\begin{equation}
(q_d,c_d,d_d,u_d)=\Pi(\mathcal I_d,S_{d,0},p_d),\qquad S_{d+1,0}=S_{d,144}.
\end{equation}
问题二的$\mathcal I_d$只包含目标日前的实际样本；问题三在四个发布时间形成$\mathcal I_{d,k}$，每次锁定已经执行的$36k$个十分钟槽；问题四只改变价格向量$p_d$，信息截面保持不变。逐日记录据此观察价格、预测来源和更新频率的综合影响；Q2与Q3的直接差值不是单因素实验。

\subsection{线性模型的矩阵化实现}
在长度为$H$的求解窗口内，程序把$q,c,d,u,e,S$按连续块组成向量，用稀疏等式约束表示能量平衡和状态递推。能量平衡、状态递推各占$H$行，初始状态和可选终端状态各增加一行；变量上下界由题目给出的功率和容量确定。问题一再加入$H$个二元变量及$2H$个大$M$不等式，形成带互斥约束的MILP。问题二至问题四在各窗口使用LP，以控制334天滚动实验的计算时间。求解后检查充放电重叠、能量平衡残差、SOC范围和计划紧急变量。

充电量和放电量均按交流侧十分钟能量记录，功率上限先乘$\Delta t=1/6$，得到833.333 kWh的单步上限，避免把kW直接与kWh相加。SOC按$S_{t+1}=S_t+\eta c_t-d_t/\eta$更新；实际缺口则用真实负荷和真实光伏重新计算。预测侧的弃光量只保证计划可行，不计入事后账单。常规购电无上限且价格为正时，计划紧急变量即使作为高价松弛保留，理论最优也应为零；程序把非零值记为审计失败。

\subsection{滚动重优化和非对称结算}
问题三、问题四-3的滚动框架在每次发布时间执行以下步骤：先读取该发布时间对应的相对小时预报；再把相对小时映射到结果模板的十分钟区间起点；接着固定已经执行的功率和SOC前缀，对未来后缀求解；最后将新计划与0:00基准计划逐时比较。若$q_t^0$是基准计划，$q_t^a$是调整后的计划，调减与调增费用分别为
\begin{equation}
C_t^{\mathrm{red}}=0.5p_t[q_t^0-q_t^a]^+,qquad C_t^{\mathrm{inc}}=1.5p_t[q_t^a-q_t^0]^+.
\end{equation}
实际缺口由式~\eqref{eq:emergency}计算，最终账单保留基准、调减、调增和紧急四个分项。这样可以分别回答“动作改变了多少”和“缺口是否减少”，也不会把滚动计划误当成无结算摩擦的重新优化。

\subsection{对照策略与评价指标}
问题二作为固定价格、每日0:00计划的主基线，问题三作为同价格滚动对照，问题四-2和问题四-3则是动态价格下的两个独立分支。四个分支使用相同的334天评估窗口、日初状态规则和实际回放公式。评价指标包括全年费用、紧急购电量、日费用中位数、P95和计划调整量；SOC边界在运行时作为硬约束审计。指定日期保留完整十分钟购电索引，并核对价格、预报发布时间、储能聚合动作和紧急区间。

预测诊断采用MAE、带非零分母保护的MAPE和平均偏差；调度结果采用费用分解，能量平衡和SOC在运行时作硬审计，超差即失败。MAPE分母为$\max(|y_t|,\varepsilon)$，负荷和光伏使用不同的$\varepsilon$，取值见本节文字。敏感性实验一次只改变一个参数，日期、价格、SOC、结算和其他预测窗口保持不变；若扩展模型改变信息集或结算规则，则重新建立配对基线，不把不同口径的数字放在同一排名中。

\subsection{实验流程与可复核输出}
一次完整实验先检查输入哈希和日期结构，再运行四问求解，随后生成逐日指标、五个结果工作簿和图形。求解过程对每个十分钟槽执行物理审计；工作簿按模板保存144点购电计划、六个四小时充放电聚合量、0:00/24:00储能状态及合并后的紧急区间，汇总JSON记录输入文件、参数、运行环境和输出列表。正文数字从该汇总与逐日表读取，图形也由同一批结果重新绘制。模型参数或代码改变后，可据此同步更新摘要、表格、图形和审计报告，减少手工抄录造成的数字漂移。

本节的实验协议还划定了结论等级：Q1在给定预测和价格下可以讨论MILP的确定性最优；Q2至Q4面对未知未来信息，只能把当前策略称为可审计研究基线。任何候选的鲁棒、随机、强化学习或启发式算法，都必须在相同信息集、相同SOC初值、相同附件3时间边界和相同结算规则下做逐日配对，并满足替换门槛：物理与账单可行率为100\%，全年总费用至少下降1\%，紧急购电P95不升，月度至少8/11个月不劣，且平均单日求解时间不超过60秒；若主张风险改善，还需使CVaR或P95至少下降5\%。未达到门槛的算法只作为对照或附录，不替换当前基线。

\section{问题一：单日确定性调度}
\subsection{混合整数线性规划}
把附件1中的预测值视为已知后，问题一只需为144个时段安排常规购电和储能动作，目标函数为
\begin{equation}\label{eq:q1obj}
\min\sum_{t=0}^{143}p_tq_t .
\end{equation}
目标函数只对常规购电计费：问题一没有紧急购电，也没有上网收益。日末SOC回到日初，避免模型通过耗尽储能换取一次性的低费用。储能是否在某时段动作，取决于当前购电成本、未来购电成本以及容量和功率边界。实现中加入$10^{-6}\sum_t(c_t+d_t)$作为破平局正则项；它只选择等价轨迹，不计入经济费用。

二元变量$z_t$满足$c_t\le5000\Delta t z_t$、$d_t\le5000\Delta t(1-z_t)$，从而禁止同一时段同时充放电。大M取单步功率上限，既保留可行动作，也不放大变量范围。求解器使用SciPy HiGHS的MILP接口，结果再通过能量平衡、SOC边界和端点条件复核；滚动优化与不确定性建模的写法参考文献\cite{gulotta,honen}。
\subsection{库存价值动态规划交叉核验}

\subsection{计划执行与紧急结算}

\begin{equation}\label{eq:emergency}
e_t=\left[L_t\Delta t-G_t\Delta t-q_t+c_t-d_t\right]^+ .
\end{equation}
相应的Q2账单为常规购电费与5倍价格紧急费之和：
\begin{equation}\label{eq:q2cost}
K_2=\sum_{t=0}^{143}\left(p_tq_t+5p_te_t\right).
\end{equation}
预测侧的松弛变量不写入实际账单；实际紧急量由式~\eqref{eq:emergency}重新计算。计划与结算分开，实际值就不会提前进入决策。

\subsection{风险扩展：保形区间与历史误差场景}
点预测只给出一个计划输入，不能说明偏差会把多少负荷推到紧急购电侧。对目标日前的校准窗口，令
\begin{equation}
 r^{L,(j)}_t=L_{j,t}-\widehat L_{j,t},\qquad r^{G,(j)}_t=G_{j,t}-\widehat G_{j,t},
\end{equation}
预测值严格按目标日当时可见的数据生成。对每个十分钟位置，分别取绝对残差的经验分位数作为半宽
\begin{equation}
 \begin{aligned}
 r_{m,\alpha}&=\min\{m,\max\{1,\lceil(m+1)(1-\alpha)\rceil\}\},\\
 \mathcal R^{X}_{d,t}&=\bigl\{|r^{X,(j)}_t|\bigr\}_{j\in\mathcal C_d},\qquad m=|\mathcal C_d|,\\
 \widehat\delta^{X}_{d,t}&=Q_{r_{m,\alpha}/m}\left(\mathcal R^{X}_{d,t}\right),\qquad X\in\{L,G\}.
 \end{aligned}
\end{equation}
并形成区间$[\widehat X_{d,t}-\widehat\delta^X_{d,t},\widehat X_{d,t}+\widehat\delta^X_{d,t}]$。分裂保形不要求误差服从正态分布，可用于检查覆盖率和区间宽度；在时间序列场景下，这只是基于滚动校准和近似交换性的边际覆盖诊断，不等同于每种天气条件下的条件保证\cite{romano}。日电量与日内形状的分解沿用时间序列预测中的层级思路\cite{hyndman}。

若要把区间信息带入调度，可保留同一日的第一阶段计划$(q,c,d,S)$，并从目标日前$K$天提取成对残差，构造场景
\begin{equation}
 L^{\omega}_t=[\widehat L_{d,t}+r^{L,(\omega)}_t]^+,qquad
 G^{\omega}_t=[\widehat G_{d,t}+r^{G,(\omega)}_t]^+,qquad \omega=1,\ldots,K .
\end{equation}
每个场景只在回放阶段产生紧急变量$e_t^\omega$，目标日实际值不会提前进入计划。场景法用于回答“近期误差方向是否持续、计划是否需要预留余量”，而不是追求一个表面上更低的费用数字。当前计划侧光伏采用0.9缩放，若将该扩展实现化，残差校准也必须明确采用缩放前还是缩放后的预测基准并保持一致；本稿尚未据此重算主结果。

\subsection{两阶段随机计划与CVaR线性化}
若用$e_t^\omega$表示场景$\omega$的紧急购电量，基本随机计划的示意形式如下。第一阶段变量$(q,c,d,u,S)$仍需满足式~\eqref{eq:balance}--\eqref{eq:bound}的非负、功率、容量、SOC递推和互斥约束；点预测计划取$e_t=0$。场景变量只在第二阶段计算紧急购电，不改变第一阶段的非预见性。
\begin{equation}\label{eq:sp}
 \begin{aligned}
 \min_{q,c,d,u,S,e^\omega}\quad&\sum_t p_tq_t+\frac{1}{K}\sum_{\omega=1}^{K}\sum_t5p_te_t^\omega,\\
 \text{s.t.}\quad &(q,c,d,u,S)\text{满足式~\eqref{eq:balance}--\eqref{eq:bound}},\\
 &e_t^\omega\ge (L_t^\omega-G_t^\omega)\Delta t-q_t+c_t-d_t,\quad e_t^\omega\ge0 .
 \end{aligned}
\end{equation}
为避免平均费用被少数低风险场景掩盖，引入置信水平$\alpha$、阈值$\xi$和超额变量$\nu_\omega$，在目标中加入
\begin{equation}\label{eq:cvar}
 \operatorname{CVaR}_{\alpha}=\xi+\frac{1}{K(1-\alpha)}\sum_{\omega=1}^{K}\nu_\omega,
 \quad \nu_\omega\ge\sum_t5p_te_t^\omega-\xi,\quad \nu_\omega\ge0 .
\end{equation}
实际目标应写成$\min\;J_{\mathrm{SP}}+\lambda\operatorname{CVaR}_{\alpha}$，其中$J_{\mathrm{SP}}$为式~\eqref{eq:sp}的期望费用，$\lambda\ge0$为无量纲的风险权衡系数。式~\eqref{eq:cvar}给出线性化约束，可交给LP求解器；它只定义候选接口，不代表本稿已经完成风险优化\cite{rockafellar}。在本工程中，这部分尚未完成334天全量重跑；$\alpha$、$K$、$\lambda$和校准集$\mathcal C_d$的具体取值也尚未固定，附件稿中四个指定日期的数字不并入当前主结果。

\subsection{预算偏差压力测试}
严格的预算鲁棒模型需要把不确定集写成可验证的对偶约束。当前对偶实现尚未完成，所以先做透明的压力测试：令$\widehat\delta^{N}_{d,t}=\widehat\delta^{L}_{d,t}+\widehat\delta^{G}_{d,t}$表示负荷升高且光伏降低时的净负荷半宽；按单位缺口成本$5p_t\widehat\delta^{N}_{d,t}\Delta t$排序，选取至多$\Gamma$个时段并增加相应净负荷，再回放计划。输出费用、紧急购电量和压力时段集合。$\Gamma$表示压力强度，不是统计置信度；完成严格鲁棒对偶并通过全量账单核验后，才能把该分支称为鲁棒优化结果\cite{bertsimas}。

\section{问题三：多时刻预报与滚动调整}
\subsection{锁定前缀的滚动基线}
每天0:00用首份24小时预报生成基准计划$q^0$；6:00、12:00、18:00收到新预报后，只重算尚未执行的时段。四次重优化起点为0、36、72、108个十分钟步，已执行前缀的$q,c,d,S$保持不变，当前末状态作为下一次优化的初始状态。各次剩余窗口为24、18、12和6小时。算法只使用当时可见的信息，不用全天真实光伏回填历史决策。
\begin{equation}
x_t^{(k)}=x_t^{\rm exec}\;(t<\tau_k),\qquad \tau_k\in\{0,36,72,108\},\qquad x=(q,c,d,S) .
\end{equation}
$\tau_k$是第$k$次预报发布对应的十分钟索引。求解器只优化$\tau_k$之后的后缀，并以前缀末端SOC为边界；已经发生的购电和储能动作不被改写。当前重优化目标先最小化后缀购电与紧急购电，调减费和调增费在事后按题面结算，所以这里称为“滚动基线”，不能称为结算感知的成本最优。负荷仍使用问题二的日期因果预测，Q3新增信息只作用于光伏后缀。需要注意，Q3的0:00基准计划使用附件3首份预报，并非Q2的三日历史中位数；因此Q2与Q3的成本差不能拆成更新时间的单独贡献。
\subsection{计划—调整结算}
令$q_t^a$为最终调整计划，$q_t^0$为0:00基准计划。两者只在尚未执行的后缀上允许不同，题面结算规则为
\begin{equation}\label{eq:settlement}
K_3=\sum_t p_tq_t^0+\sum_t0.5p_t[q_t^0-q_t^a]^++\sum_t1.5p_t[q_t^a-q_t^0]^++\sum_t5p_te_t .
\end{equation}
逐日记录基准费、调减费、调增费和紧急费，并检查四项之和。结算时始终以$q^0$计入基准费，调整部分按计划差额分为调减和调增两项：减少计划量按0.5倍价格计费，增加计划量按1.5倍价格计费，避免把最终调整计划误当作基准计划。

题面中的“计划购电费用”和“调整购电量相关费用”存在解释空间。当前口径把$q^0$视为已申报且按原价结算的基准量，偏离部分再按0.5倍或1.5倍价格计费。若$q_t^a<q_t^0$时，费用为$p_tq_t^0+0.5p_t(q_t^0-q_t^a)$。若把“50\%违约电价”理解为取消部分不再支付原计划电费，则替代口径为
\begin{equation}
K_3^{\mathrm{alt}}=\sum_t p_t\min(q_t^0,q_t^a)+\sum_t0.5p_t[q_t^0-q_t^a]^++\sum_t1.5p_t[q_t^a-q_t^0]^++\sum_t5p_te_t .
\end{equation}
两种解释会改变全年费用和策略排序。当前主结果采用前一口径，替代口径尚未重跑；正式提交前应结合组委会解释或题面上下文裁定，并将另一口径作为结算敏感性。

\subsection{结算感知的更新触发条件}
设第$k$次更新使后缀紧急购电费用减少$\Delta C_{\mathrm{emg}}>0$，并定义常规计划费用变化为$\Delta C_{\mathrm{plan}}=C_{\mathrm{plan}}^{\mathrm{new}}-C_{\mathrm{plan}}^{\mathrm{old}}$，调整费用为$C_{\mathrm{adj}}$。只有满足
\begin{equation}\label{eq:trigger}
 \Delta C_{\mathrm{emg}}-\Delta C_{\mathrm{plan}}>C_{\mathrm{adj}}
\end{equation}
时，更新才具有正的账面边际收益。式~\eqref{eq:trigger}给出可核对的账面条件：若新预报只带来小幅计划变化，调整费可能抵消紧急费节约；若SOC已接近边界，新增信息也未必有可执行的调度空间。当前基线尚未把$C_{\mathrm{adj}}$放回滚动优化目标，后续需增加差额辅助变量，与当前启发式基线做同日配对比较。

\subsection{结果解读与边界}
与Q2相比，Q3滚动基线全年费用增加971586.82元（6.00\%），紧急购电量增加22093.208\,kWh（2.80\%），出现正紧急量的日期由316天增至334天。这个比较同时混入了0:00光伏预测源的替换、后续预报更新和当前结算口径，只反映当前启发式执行口径下的综合账单，不能据此断言信息更新本身有害。若要比较策略优劣，需要把式~\eqref{eq:trigger}对应的调整费纳入重优化，并在相同日初SOC下做配对实验。
若要单独识别更新时间的价值，应增加同一0:00光伏预测源下“不更新”的Q3-0对照，或让Q3在0:00沿用Q2的历史预测，再与四次更新分支配对；当前主结果尚未运行这组对照。
图~\ref{fig:adjust}中，334个评估日的Pearson相关系数为0.0201（计划—调整绝对差与紧急购电量）。计划改动幅度与实际缺口并不一一对应。散点图只展示这种解耦关系，不构成滚动策略因果改善的证据；策略比较仍需在相同日初SOC、价格和信息集下独立回测，并报告费用、紧急量和调整量的联合分布。

从执行角度看，滚动策略能否获益，取决于新预报到达时储能是否还有调节余量，以及调整是否落在高价时段。SOC接近边界时，新增信息可能无法转化为动作；调整落在高价时段时，费用还可能上升。所以Q3是带结算摩擦的在线策略实验，不能简化为“更新次数越多越好”。

\subsection{对抗性分支核验}
稳健性核验先检查账单恒等式，再检查各分支中应保持或应改变的量。Q3和Q4-3的全年账单按“计划基准费+调减费+调增费+紧急费”逐日相加；Q4-2在附件4价格下独立重算调度。若要验证纯价格结算效应，还需计算固定Q2动作的反事实，不能用紧急总量相同代替逐时动作核对。外部经验贴只用于方法讨论，其中未经复现的数字和未来信息路径不写入主结果。

当前结果中，Q4-2与Q2的全年紧急购电量差异小于$10^{-9}$\,kWh，但逐时计划不同。这只能说明本地回放的总缺口恰好一致，不能说明价格替换没有改变调度。Q4-3比Q3增加767005.80元（4.47\%），紧急购电量只增加5.531\,kWh（0.0007\%）。动态价格的影响同时落在价格暴露、储能时序和调增/调减结算上。

信息边界已按代码路径建立核对清单：目标日负荷和光伏点预测只从目标日前观测构造，实际负荷与实际光伏只在事后紧急结算中使用；附件3相对发布时间的小时偏移已按“发布时刻+1--24小时”映射，首个预测点之前采用首值保持的边界填充仍是待敏感性核验的实现选择；Q3结算费尚未进入滚动目标。当前评估窗口以6000\,kWh非连续暖启动，尚未从2025年1月1日连续预热到2月1日，需在修复后重跑并做提交级复核。Q4当前基线把附件4当天的144个价格点视为0:00可见并直接用于日内优化，这是为完成题目重算而作的显式实现假设；若“实时波动”意味着价格逐时揭示，则应改为价格预测或已揭示窗口的滚动策略，当前Q4数值不能直接解释为该口径下的因果价格效应。Q1的MILP与5\,kWh网格DP使用同一日初、日末储能条件，结果工作簿保留计划列和模板聚合结果，可继续作为基线。

\subsection{局限与待办修复}
当前主结果使用单一路径预测。本轮补充了保形、场景和CVaR的数学接口，但尚未完成334天全量重算，扩展方法不能写成已经验证的性能提升。模型还未纳入通信延迟、电池退化、负荷可移峰以及负荷—光伏联合误差。敏感性表只回答“在当前回测窗口改变一个参数会怎样”，不能替代概率稳健性结论。

回测覆盖附件年度中的334天，采用确定性单一路径预测；seed只写入复现清单作版本标记。结果可支持本地复现和方法比较，不能外推到其他年份或真实运行系统。若引入鲁棒或随机模型，应先明确场景生成和风险预算，再重算结果、图表并复核账单恒等式。

\section{模型评价与推广}
\subsection{模型的可取之处}
四问共用能量平衡和储能状态递推，差异只来自信息集、价格序列和结算方式，结果可以追溯到具体机制。问题一用互斥MILP给出基准，再用网格DP核对库存价值；问题二和问题三把“预测用于决策、实际用于回放”落实为程序接口，减少未来信息泄漏。保形区间、历史误差场景和CVaR给出预测诊断到风险调度的扩展接口，但尚未构成主结果。指定日期、全年分项账单和压力测试同时报告费用、紧急电量和SOC，避免单一指标承载全部结论。

\subsection{局限与推广方向}
当前结果受以下工程边界约束：评估窗口从6000\,kWh非连续暖启动，跨日SOC尚未从1月连续传递到2月起点；日计划没有终端库存价值，日末SOC反复落在下限；Q3滚动目标尚未内生化调减/调增费；B结算中“计划基准费是否对取消量继续收取”存在题意解释风险，当前主结果采用全额基准加差额费用，替代口径尚未重算；Q4价格是否在0:00已知也未由题面明确，当前结果按全天价格可见处理。当前主稿已补入六个十分钟购电量、六个四小时充放电量和0/24时SOC；结果工作簿通过了日期前向填充与区间语义审计，但仍需按模板逐格验收，Q4指定日期如需同样版式也应补入提交包。这些问题无法靠增加文字解决，必须回到代码和结果文件修复。修复后优先做四组配对实验：双结算口径、结算感知滚动模型与当前基线、动态价格重算与固定动作换价反事实、5/1/0.5 kWh DP网格收敛。随后再将场景SP+CVaR扩展到全量回测，并报告均值、P95、紧急电量和计算时间的联合变化。更长期可加入带时间相关性的预测区间、电池退化成本、多日模型和可中断负荷需求响应。

\section{结论与可复现性}
四问共用十分钟能量平衡模型，但各问保留自己的信息边界和评价口径。问题一用互斥MILP得到单日基准，5\,kWh网格DP在相同日初、日末SOC条件下独立核验库存价值；问题二用日期因果预测完成全年计划和实际缺口结算，但日计划没有终端库存价值，仍是短视基线；问题三把新预报转化为锁定前缀后的滚动再决策，并按题面规则拆分计划、调减、调增和紧急费用；问题四分别从问题二和问题三启动动态价格分支。纯价格结算效应仍需与固定Q2动作的反事实分支配对。

主要结果与题面任务对应如下：问题一MILP经济费用为35126.95元，求解器内部目标值为35126.99元，网格DP与经济费用相差0.0684\%；问题二334天回测的费用和紧急购电量分别为16206550.45元、789872.052\,kWh；问题三为17178137.27元、811965.260\,kWh。相对Q2，滚动调整使费用增加971586.82元（6.00\%），紧急购电量增加22093.208\,kWh（2.80\%）。这个差异同时受到预测源、再决策过程和结算口径影响，不能直接归因于某一种算法。

动态价格独立重算分支Q4-2费用为16989713.48元，与Q2的紧急购电量差异小于$10^{-9}$\,kWh，但逐时动作已经重排。波动价格滚动分支Q4-3费用为17945143.08元，比Q3高767005.80元（4.47\%），紧急购电量只高5.531\,kWh（0.0007\%）。波动价格的影响同时体现为价格暴露、储能时序和调增/调减结算变化。

def solve_dispatch(load_kw,pv_kw,price,initial=S_INIT,terminal=None, emergency=True, pv_is_forecast=True, mutex=False):

    H=len(load_kw)

        if emergency: row[ie+t]=1
        Aeq.append(row); beq.append(float(load_kw[t]-pv_kw[t])*DT)
        row=np.zeros(n); row[is0+t+1]=1; row[is0+t]=-1; row[ic+t]=-ETA; row[id+t]=1/ETA
        Aeq.append(row); beq.append(0)
    if terminal is not None:

    # charging/discharging limits

    if mutex:

def audit_dispatch(result, initial, terminal=None, *, load_kw=None, pv_kw=None, tol=1e-5):
    """Fail fast on physical violations before a result reaches the bill."""
    c,d,q,u,e,s = (np.asarray(result[k], dtype=float) for k in ('c','d','q','u','e_plan','s'))
    if np.min(c) < -tol or np.min(d) < -tol or np.min(q) < -tol or np.min(u) < -tol or np.min(e) < -tol:
        raise AssertionError('negative dispatch variable')
    if np.max(c) > P_MAX + tol or np.max(d) > P_MAX + tol:
        raise AssertionError('charge/discharge power bound violated')
    if np.min(s) < S_MIN - tol or np.max(s) > S_MAX + tol:
        raise AssertionError('SOC bound violated')
    # Planned emergency energy is only a high-cost feasibility slack.  With
    # unbounded regular grid purchase and positive prices it should be zero;
    # fail fast if a solver ever uses it in the planned trajectory.
    if np.max(e) > tol:
        raise AssertionError('planned emergency variable is nonzero')
    if abs(float(s[0]) - float(initial)) > tol:
        raise AssertionError('initial SOC mismatch')
    if terminal is not None and abs(float(s[-1]) - float(terminal)) > tol:
        raise AssertionError('terminal SOC mismatch')
    balance_residual = 0.0
    soc_residual = 0.0
    if (load_kw is None) != (pv_kw is None):
        raise ValueError('load_kw and pv_kw must be supplied together')
    if load_kw is not None:
        load_arr = np.asarray(load_kw, dtype=float)
        pv_arr = np.asarray(pv_kw, dtype=float)
        if load_arr.shape != q.shape or pv_arr.shape != q.shape:
            raise ValueError('audit inputs must match dispatch horizon')
        balance = q + e + d + pv_arr * DT - load_arr * DT - c - u
        state = s[1:] - s[:-1] - ETA * c + d / ETA
        balance_residual = float(np.max(np.abs(balance)))
        soc_residual = float(np.max(np.abs(state)))
        if balance_residual > tol:
            raise AssertionError(f'energy balance residual {balance_residual:.3g}')
        if soc_residual > tol:
            raise AssertionError(f'SOC recursion residual {soc_residual:.3g}')
    overlap=float(np.minimum(c,d).sum())
    return {'overlap_kwh': overlap, 'soc_min': float(s.min()), 'soc_max': float(s.max()),
            'balance_residual_kwh': balance_residual, 'soc_residual_kwh': soc_residual}

def interp_forecast(vals24, release_hour=0):
    """Map release-relative +1..+24 h forecasts to the template's 10-min slots.

    Input and result-template columns are labelled by interval start (0:10,
    ..., 0:00+1), while attachment 3 reports the first forecast one hour
    after the release.  Values before the first released hour use the first
    forecast as a causal hold; later values are linearly interpolated.
    """
    x=release_hour*60+np.arange(24)*60+60
    y=np.asarray(vals24,dtype=float)
    target=np.arange(T)*10+10
    return np.interp(target,x,y,left=y[0],right=y[-1])

def actual_emergency(load_kw,pv_kw,plan,c,d,u):

def rolling_plan(Lhat, pv_forecast, price, initial):
    """Four 6-hour rolling updates; lock each executed prefix before re-solving."""

"""Small, auditable building blocks for the C题 adversarial update.

The module deliberately keeps the settlement rule and the inventory-value
calculation independent from the long back-test driver.  This makes it harder
to accidentally change a billing convention while changing a forecast.
"""
from __future__ import annotations

from datetime import date, timedelta
from typing import Iterable

import numpy as np


def settlement_b(plan: np.ndarray, adjusted: np.ndarray, price: np.ndarray) -> dict:
    """Return the Q3 bill under the wording in the statement.

    The planned quantity is billed at the normal price.  A reduction relative
    to the plan is charged at 0.5 times the transaction price and an increase
    is charged at 1.5 times that price.  The returned components are useful in
    the paper and prevent the common mistake of billing the adjusted quantity
    as if it were the original plan.
    """
    plan = np.asarray(plan, dtype=float)
    adjusted = np.asarray(adjusted, dtype=float)
    price = np.asarray(price, dtype=float)
    if not (plan.shape == adjusted.shape == price.shape):
        raise ValueError("plan, adjusted and price must have the same shape")
    reduction = np.maximum(plan - adjusted, 0.0)
    increase = np.maximum(adjusted - plan, 0.0)
    base = price * plan
    reduction_fee = 0.5 * price * reduction
    increase_fee = 1.5 * price * increase
    return {
        "base": float(base.sum()),
        "reduction_fee": float(reduction_fee.sum()),
        "increase_fee": float(increase_fee.sum()),
        "total": float((base + reduction_fee + increase_fee).sum()),
        "reduction_kwh": float(reduction.sum()),
        "increase_kwh": float(increase.sum()),
    }


def settlement_b_vector(plan: np.ndarray, adjusted: np.ndarray, price: np.ndarray) -> float:
    """Scalar convenience wrapper used by vectorized back-tests."""
    return settlement_b(plan, adjusted, price)["total"]


def forecast_load_decomposed(load, target: date, dates: Iterable[date], dt: float,
                             same_type_window: int = 8) -> np.ndarray:
    """Causal daily-level/shape load forecast.

    Only dates strictly before ``target`` are considered.  Recent days with
    the same weekday are preferred; if fewer than three exist, all recent days
    are used.  The daily energy level and normalized intraday shape are
    estimated separately, so a high-load day does not distort the shape of a
    low-load day.  ``load`` is a date-indexed dataframe in kW.
    """
    target = target if isinstance(target, date) else target.date()
    all_dates = list(dates)
    prior = [d for d in all_dates if d < target and d in load.index]
    if not prior:
        return np.full(load.shape[1], 6000.0)
    same = [d for d in prior if d.weekday() == target.weekday()][-same_type_window:]
    chosen = same if len(same) >= 3 else prior[-same_type_window:]
    arr = np.asarray(load.loc[chosen].values, dtype=float)
    daily = np.nansum(arr * dt, axis=1)
    safe = np.where(daily > 1e-9, daily, 1.0)
    shape = arr / safe[:, None] / dt
    level = float(np.nanmedian(daily))
    profile = np.nanmedian(shape, axis=0)
    profile = np.maximum(profile, 0.0)
    norm = float(np.nansum(profile * dt))
    if not np.isfinite(norm) or norm <= 1e-9:
        return np.nanmedian(arr, axis=0)
    return level * profile / norm


def finite_grid_value_dp(net_load_kwh: np.ndarray, price: np.ndarray, *,
                         initial: float, terminal: float, s_min: float,
                         s_max: float, eta: float, p_max_kwh: float,
                         step: float = 20.0) -> dict:
    """Approximate the deterministic inventory value function on a grid.

    The state is internal battery energy.  For each state transition only one
    of charge/discharge is used, so the recursion is physically explicit and
    avoids a hidden simultaneous-charge/discharge degree of freedom.  The
    result is an *independent numerical cross-check* for the LP, not a claim
    that the grid is an exact continuous DP.
    """
    n = len(net_load_kwh)
    net_load_kwh = np.asarray(net_load_kwh, dtype=float)
    price = np.asarray(price, dtype=float)
    if net_load_kwh.shape != price.shape:
        raise ValueError("net load and price must have the same length")
    grid = np.arange(s_min, s_max + 0.5 * step, step, dtype=float)
    if not np.any(np.isclose(grid, initial)) or not np.any(np.isclose(grid, terminal)):
        raise ValueError("initial and terminal must lie on the DP grid")
    terminal_idx = int(np.argmin(np.abs(grid - terminal)))
    value = np.full((n + 1, grid.size), np.inf, dtype=float)
    value[n, terminal_idx] = 0.0
    policy = np.full((n, grid.size), -1, dtype=int)
    for t in range(n - 1, -1, -1):
        for i, s in enumerate(grid):
            # A discharge of d kWh lowers internal SOC by d/eta, while a
            # charge of c kWh raises it by eta*c; the reachable window is
            # therefore asymmetric when eta != 1.
            lo = max(s_min, s - p_max_kwh / eta)
            hi = min(s_max, s + p_max_kwh * eta)
            js = np.flatnonzero((grid >= lo - 1e-9) & (grid <= hi + 1e-9))
            delta = grid[js] - s
            charge = np.maximum(delta, 0.0) / eta
            discharge = np.maximum(-delta, 0.0) * eta
            grid_cost = price[t] * np.maximum(net_load_kwh[t] + charge - discharge, 0.0)
            cand = grid_cost + value[t + 1, js]
            if cand.size:
                k = int(np.argmin(cand))
                value[t, i] = cand[k]
                policy[t, i] = int(js[k])
    initial_idx = int(np.argmin(np.abs(grid - initial)))
    return {
        "grid": grid,
        "value": value,
        "policy": policy,
        "initial_value": float(value[0, initial_idx]),
        "grid_step_kwh": float(step),
        "reachable": int(np.isfinite(value[0]).sum()),
    }


def dp_policy_rollout(dp: dict, net_load_kwh: np.ndarray, price: np.ndarray,
                      initial: float, eta: float) -> dict:
    """Roll out a grid-DP policy and return charge/discharge/purchase arrays."""
    grid = dp["grid"]
    idx = int(np.argmin(np.abs(grid - initial)))
    charge = np.zeros(len(net_load_kwh))
    discharge = np.zeros(len(net_load_kwh))
    purchase = np.zeros(len(net_load_kwh))
    states = np.zeros(len(net_load_kwh) + 1)
    states[0] = grid[idx]
    for t, net in enumerate(np.asarray(net_load_kwh, dtype=float)):
        nxt = int(dp["policy"][t, idx])
        if nxt < 0:
            raise RuntimeError("DP policy is infeasible at rollout state")
        delta = grid[nxt] - grid[idx]
        if delta >= 0:
            charge[t] = delta / eta
        else:
            discharge[t] = -delta * eta
        purchase[t] = max(0.0, net + charge[t] - discharge[t])
        states[t + 1] = grid[nxt]
        idx = nxt
    return {"q": purchase, "c": charge, "d": discharge, "s": states,
            "cost": float(np.dot(price, purchase))}
\end{verbatim}

\subsection*{工作簿语义审计：\texttt{scripts/validate\_workbook\_semantics.py}}
\begin{verbatim}
"""Semantic audit for the six four-hour storage rows in result workbooks.

The template merges the date cell vertically, so blank date cells are expected
on rows 2--6 of each day.  This audit forward-fills that display convention,
then checks the actual date/interval/SOC semantics independently of the writer.
"""
from __future__ import annotations

from datetime import date, datetime, time, timedelta
import math
from pathlib import Path

from openpyxl import load_workbook

ROOT = Path(__file__).resolve().parents[1]
OUT = ROOT / "results"
START = date(2025, 2, 1)
END = date(2025, 12, 31)
DATES = [START + timedelta(days=i) for i in range((END - START).days + 1)]
INTERVALS = ["0:00-4:00", "4:00-8:00", "8:00-12:00",
             "12:00-16:00", "16:00-20:00", "20:00-24:00"]
FILES = ("result2.xlsx", "result3.xlsx", "result4-2.xlsx", "result4-3.xlsx")
TOL = 1e-6


def as_date(value):
    if isinstance(value, datetime):
        return value.date()
    if isinstance(value, date):
        return value
    return None


def audit(path: Path) -> dict:
    ws = load_workbook(path, read_only=True, data_only=True)["充放电量"]
    rows = []
    current_date = None
    for row in ws.iter_rows(min_row=2, values_only=True):
        if not row or row[1] is None:
            continue
        d = as_date(row[0])
        if d is not None:
            current_date = d
        if current_date is None:
            raise AssertionError(f"{path.name}: first data row has no date")
        rows.append((current_date, row[1], row[2], row[3], row[4], row[5]))

    if len(rows) != len(DATES) * 6:
        raise AssertionError(f"{path.name}: expected {len(DATES)*6} rows, got {len(rows)}")
    dates = [r[0] for r in rows[::6]]
    if dates != DATES:
        raise AssertionError(f"{path.name}: date sequence is not {START}..{END}")

    end_socs = []
    for i, d in enumerate(DATES):
        block = rows[i * 6:(i + 1) * 6]
        if [r[1] for r in block] != INTERVALS:
            raise AssertionError(f"{path.name}: interval labels differ on {d}")
        if not math.isfinite(float(block[0][5])):
            raise AssertionError(f"{path.name}: invalid 0:00 SOC on {d}")
        if not isinstance(block[0][4], time) or block[0][4] != time(0, 0):
            raise AssertionError(f"{path.name}: missing 0:00 marker on {d}")
        if str(block[1][4]) != "24:00":
            raise AssertionError(f"{path.name}: missing 24:00 marker on {d}")
        for r in block:
            if float(r[2]) < -TOL or float(r[3]) < -TOL:
                raise AssertionError(f"{path.name}: negative charge/discharge on {d}")
        soc0 = float(block[0][5])
        soc24 = float(block[1][5])
        if not (1200 - TOL <= soc0 <= 10800 + TOL):
            raise AssertionError(f"{path.name}: 0:00 SOC out of bounds on {d}")
        if not (1200 - TOL <= soc24 <= 10800 + TOL):
            raise AssertionError(f"{path.name}: 24:00 SOC out of bounds on {d}")
        end_socs.append(soc24)

    return {
        "file": path.name,
        "rows": len(rows),
        "dates": len(set(r[0] for r in rows)),
        "end_soc_records": len(end_socs),
        "end_soc_min": min(end_socs),
        "end_soc_max": max(end_socs),
        "lower_bound_end_count": sum(abs(x - 1200.0) <= TOL for x in end_socs),
        "first_day_soc0": float(rows[0][5]),
        "last_day_soc24": float(end_socs[-1]),
    }


if __name__ == "__main__":
    for filename in FILES:
        print(audit(OUT / filename))
    print("PASS workbook semantic validation")

\subsection*{图形导出：\texttt{scripts/export\_figure.py}}
\begin{verbatim}
"""
scipilot-figure-skill :: export_figure.py
=========================================
Unified figure export to multiple formats at exact final size.

- Vector preferred: PDF / SVG / EPS for line/bar/scatter (lossless, journal-friendly).
- Raster for photos / micrographs: PNG / TIFF at >= 300 DPI; never JPEG for data figures.
- Embeds TrueType fonts (fonttype 42) so journals don't reject Type-3 PDFs.
- Optional grayscale preview to sanity-check colorblind safety.

Usage
-----
    from export_figure import export_figure
    import matplotlib.pyplot as plt

    fig, ax = plt.subplots()
    ax.plot([0,1,2],[3,1,4])

    paths = export_figure(
        fig,
        basename="figs/fig1_main",
        formats=["pdf", "svg", "png"],
        size_inches=(3.5, 2.625),   # 强制成 Nature 单栏尺寸
        dpi=600,
        grayscale_preview=True,
    )
    # -> ['figs/fig1_main.pdf', 'figs/fig1_main.svg',
    #     'figs/fig1_main.png', 'figs/fig1_main_grayscale.png']

CLI: ``python export_figure.py demo`` 生成一张演示图并多格式导出。
"""
from __future__ import annotations

import argparse
import os
import sys
from typing import Iterable

import matplotlib.pyplot as plt


VECTOR_FORMATS = {"pdf", "svg", "eps"}
RASTER_FORMATS = {"png", "tiff", "tif", "jpg", "jpeg"}
SUPPORTED_FORMATS = VECTOR_FORMATS | RASTER_FORMATS


def _ensure_parent(path: str) -> None:
    parent = os.path.dirname(os.path.abspath(path))
    if parent and not os.path.exists(parent):
        os.makedirs(parent, exist_ok=True)


def export_figure(
    fig,
    basename: str,
    formats: Iterable[str] | None = None,
    dpi: int = 300,
    size_inches: tuple[float, float] | None = None,
    grayscale_preview: bool = False,
    tight: bool = True,
    pad_inches: float = 0.05,
    transparent: bool = False,
) -> list[str]:
    """
    Export a matplotlib Figure to one or more formats at exact final size.

    Args:
        fig: matplotlib Figure object.
        basename: 输出路径前缀（不含扩展名）；可包含子目录，自动创建。
        formats: list/tuple of extensions, e.g. ['pdf', 'svg', 'png'].
            Default: ['pdf', 'svg', 'png'].
        dpi: raster 格式分辨率；建议 300（普通）/ 600（IEEE 等）。
        size_inches: (width, height) 英寸；指定后会 fig.set_size_inches() 强制
            最终尺寸。强烈建议传入——保证导出后不必在 Word/LaTeX 里二次缩放。
        grayscale_preview: 额外生成一张 _grayscale.png 供色盲安全检查。
        tight: 是否走 bbox_inches='tight'（裁掉留白）。
        pad_inches: tight 模式下保留的边距（英寸）。
        transparent: 透明背景（PPT/海报可能需要）。

    Returns:
        实际写出的文件路径列表。
    """
    if formats is None:
        formats = ("pdf", "svg", "png")
    formats = [f.lower().lstrip(".") for f in formats]
    unknown = [f for f in formats if f not in SUPPORTED_FORMATS]
    if unknown:
        raise ValueError(f"Unsupported formats: {unknown}. "
                         f"Supported: {sorted(SUPPORTED_FORMATS)}")

    if size_inches is not None:
        if len(size_inches) != 2:
            raise ValueError("size_inches must be (width, height)")
        fig.set_size_inches(*size_inches)

    # 强制嵌入 TrueType 字体（fonttype 42）；多家期刊明确拒绝 Type-3 PDF。
    plt.rcParams["pdf.fonttype"] = 42
    plt.rcParams["ps.fonttype"] = 42
    plt.rcParams["svg.fonttype"] = "none"  # 文本仍可编辑，期刊通常更欢迎

    saved: list[str] = []
    for fmt in formats:
        if fmt in {"jpg", "jpeg"}:
            print(f"[scipilot-figure-skill] WARNING: skipping {fmt} — "
                  "JPEG is lossy and unsuitable for line/text figures.",
                  file=sys.stderr)
            continue
        path = f"{basename}.{fmt}"
        _ensure_parent(path)
        kwargs: dict = {
            "bbox_inches": "tight" if tight else None,
            "pad_inches": pad_inches,
            "transparent": transparent,
        }
        if fmt in RASTER_FORMATS:
            kwargs["dpi"] = dpi
        fig.savefig(path, **kwargs)
        saved.append(path)
        print(f"[scipilot-figure-skill] wrote {path}")

    if grayscale_preview:
        gray_path = _grayscale_from(fig, basename, dpi=dpi)
        if gray_path:
            saved.append(gray_path)
    return saved


def _grayscale_from(fig, basename: str, dpi: int) -> str | None:
    """
    导出灰度预览版用于色盲安全检查。
    优先用 PIL 转灰度；找不到 PIL 时退化为重新画图（关闭颜色）。
    """
    try:
        from PIL import Image
    except ImportError:
        print("[scipilot-figure-skill] Pillow not available; "
              "grayscale preview skipped.", file=sys.stderr)
        return None

    png_path = f"{basename}.png"
    _ensure_parent(png_path)
    fig.savefig(png_path, dpi=dpi, bbox_inches="tight")

    gray_path = f"{basename}_grayscale.png"
    Image.open(png_path).convert("L").save(gray_path)
    print(f"[scipilot-figure-skill] wrote {gray_path} (grayscale preview)")
    return gray_path


def _demo(out_basename: str) -> None:
    """Generate a small demo figure for quick smoke testing."""
    import numpy as np
    rng = np.random.default_rng(7)
    x = np.linspace(0, 10, 50)
    y1 = np.sin(x) + rng.normal(0, 0.1, x.size)
    y2 = np.cos(x) + rng.normal(0, 0.1, x.size)

    fig, ax = plt.subplots(figsize=(3.5, 2.625))
    ax.plot(x, y1, label="sin", marker="o", markersize=3)
    ax.plot(x, y2, label="cos", marker="s", markersize=3, linestyle="--")
    ax.set_xlabel("x")
    ax.set_ylabel("y")
    ax.legend(frameon=False)

    paths = export_figure(
        fig, out_basename,
        formats=["pdf", "svg", "png"],
        size_inches=(3.5, 2.625),
        dpi=300,
        grayscale_preview=True,
    )
    print("\nDemo done. Files:")
    for p in paths:
        print(f"  {p}")


def _cli() -> int:
    p = argparse.ArgumentParser(description="scipilot-figure-skill figure exporter")
    p.add_argument("cmd", choices=["demo"], help="`demo`: 跑一张演示图导出 4 种格式")
    p.add_argument("--out", default="./scipilot_demo",
                   help="输出 basename (默认 ./scipilot_demo)")
    args = p.parse_args()
    if args.cmd == "demo":
        _demo(args.out)
    return 0


if __name__ == "__main__":
    sys.exit(_cli())
